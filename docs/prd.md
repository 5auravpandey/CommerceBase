# Product Requirements Document: CommerceBase
**Goal:** A dynamic, database-driven e-commerce platform built as a BCA Final Year Major Project.
**Core Features:**
- Customer Flow: Authentication, dynamic product catalog browsing, cart management, and checkout.
- Admin Flow: Secure dashboard, product management, and dynamic theme/branding control.
- Security First: Protection against XSS, SQL Injection, and Tomcat stack trace leaks.
