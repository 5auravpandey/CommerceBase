# UI/UX Guidelines (Clean E-Commerce Pivot)
We are building a clean, minimalist, and trusted e-commerce platform using Tailwind CSS. 

**REQUIRED DESIGN LANGUAGE:**
- **Style:** Clean, minimalist, and consumer-friendly (similar to a premium Shopify theme).
- **Corners & Borders:** Use standard rounded corners (`rounded-md` or `rounded-lg`) and subtle borders (`border border-gray-200`).
- **Depth & Interaction:** Use soft and realistic drop shadows on product cards and containers (`shadow-sm hover:shadow-md transition-shadow`).
- **Typography:** Proper text casing (Title Case for products/headings, normal casing for descriptions). Do NOT use excessive uppercase text. Use standard system UI fonts.
- **Colors:** Use off-white/light gray for page backgrounds (`bg-gray-50`) and crisp white (`bg-white`) for cards and containers to make them pop.
- **Theming:** Use the dynamic database color `${storeConfig.themeColor}` for primary buttons, active states, and the navbar.
